# Subarray Product Less Than K

## Problem Link

[LeetCode 713 - Subarray Product Less Than K](https://leetcode.com/problems/subarray-product-less-than-k/)

## Problem Statement

Given an array of integers `nums` and an integer `k`, return the number of contiguous subarrays where the product of all the elements in the subarray is strictly less than `k`.

---

## Example 1

### Input

```text
nums = [10,5,2,6]
k = 100
```

### Output

```text
8
```

### Explanation

The 8 subarrays with product less than 100 are:

```text
[10]
[5]
[2]
[6]
[10,5]
[5,2]
[2,6]
[5,2,6]
```

The subarray `[10,5,2]` is not counted because its product equals `100`, which is not strictly less than `100`.

---

## Example 2

### Input

```text
nums = [1,2,3]
k = 0
```

### Output

```text
0
```

### Explanation

No positive product can be less than `0`.

---

# Approach: Sliding Window

## Idea

- Maintain a sliding window whose product is always less than `k`.
- Expand the window by moving the `right` pointer.
- If the product becomes greater than or equal to `k`, shrink the window from the left.
- For every valid window, count all subarrays ending at the current `right` index.

---

## Code

```python
def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:

    if k <= 1:
        return 0

    product = 1
    left = 0
    count = 0

    for right in range(len(nums)):

        product *= nums[right]    # Expand window

        while product >= k:
            product //= nums[left]  # Shrink window
            left += 1

        count += right - left + 1  # Count valid subarrays

    return count
```

---

# Important Lines Explained

### Handle Edge Case

```python
if k <= 1:
    return 0
```

If `k` is `0` or `1`, no positive product can be strictly less than `k`.

---

### Expand Window

```python
product *= nums[right]
```

Include the current element in the sliding window product.

---

### Shrink Window

```python
while product >= k:
```

If the current product is invalid, reduce the window size from the left.

---

### Remove Left Element

```python
product //= nums[left]
left += 1
```

Remove the leftmost element from the product and move the left pointer.

---

### Count Valid Subarrays

```python
count += right - left + 1
```

All subarrays ending at `right` and starting between `left` and `right` are valid.

For example:

```text
Window = [5,2,6]

Valid subarrays ending at 6:

[6]
[2,6]
[5,2,6]

Count = 3
```

which equals:

```python
right - left + 1
```

# Dry Run

Input:

```text
nums = [10,5,2,6]

```

| Left | Right | Product | New Subarrays | Count |
|--------|---------|---------|---------|---------|
| 0 | 0 | 10 | [10] | 1 |
| 0 | 1 | 50 | [5], [10,5] | 3 |
| 1 | 2 | 10 | [2], [5,2] | 5 |

```text

```

# Complexity Analysis

### Time Complexity

```text
O(n)
```

Each element enters and leaves the sliding window at most once.

### Space Complexity

```text
O(1)
```

Only a few variables are used.
